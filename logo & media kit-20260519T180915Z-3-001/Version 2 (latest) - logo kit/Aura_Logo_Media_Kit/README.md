# Aura Logo Media Kit

Official export-ready media kit for **Aura — Relationship AI**.

## Included

- `01_Source_SVG/` — editable source SVGs for the primary, gradient, monochrome, reverse, and icon-only logo system.
- `02_PDF_Vector/` — vector PDF exports for print and press workflows.
- `03_PNG_Transparent/` — transparent PNG exports for product/UI usage.
- `04_App_Icons/` — Google Play app icon, Android adaptive icon resources, legacy launcher icons, and favicons.
- `05_Social_and_Store_Graphics/` — Google Play feature graphic, GitHub banner, documentation header, X cover, and LinkedIn cover.
- `06_Brand_Guidelines/` — quick brand and logo usage guide PDF.
- `07_Developer_Tokens/` — JSON, CSS, and Jetpack Compose/Kotlin color tokens.
- `08_Reference_Uploads/` — source reference files supplied for the media kit.

## Core Logo Rules

- Use the primary full-color logo on light backgrounds.
- Use the reverse/white lockup on dark backgrounds, gradients, or photography.
- Keep clear space around the logo at least equal to the height of the letter **A** in the wordmark.
- Do not stretch, rotate, skew, recolor, lower opacity, or place the logo on busy backgrounds.
- Minimum digital logo height: 64px.
- Minimum print logo height: 0.5 inches.
